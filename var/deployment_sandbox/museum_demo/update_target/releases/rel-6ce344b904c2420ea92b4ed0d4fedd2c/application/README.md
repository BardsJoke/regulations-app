# Museum Collection Registry Demo 1.0.0

Исходная версия для лабораторной отработки обновления и отката.

Возможности: просмотр демонстрационной коллекции и карточек предметов.

Запуск из корня релиза:

```powershell
uv run python application/main.py
```

Данные полностью вымышленные и не содержат сведений о реальных музейных фондах.
